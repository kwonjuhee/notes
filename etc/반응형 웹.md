
# 미디어 쿼리

![Untitled](attachments/반응형%20웹/Untitled.png)

- only는 뒤의 조건만을 뜻한다. 미디어 쿼리를 지원하지 않는 브라우저는 only 키워드가 있을 경우 쿼리 안의 내용이 무시되어 실행되지 않는다.
- not은 뒤의 조건을 제외한 조건을 뜻한다.
- 미디어타입 종류
    - all : 모든 미디어 타입
    - screen : 컴퓨터 스크린 ⇒ 대부분의 컴퓨터와 모바일 기기
    - print : 인쇄 용도
- 미디어쿼리 속성은 min-, max-를 붙여 최솟값, 최댓값을 나타내고 and로 나열하여 범위를 나타낼 수 있다.

# 유동형 그리드(Fluid Grid)

**그리드**는 웹 화면의 폭을 몇개의 컬럼으로 나누는 것을 말한다. 컬럼들의 폭과 다른 컬럼과의 간격을 일정하게 유지한다.

![Untitled](attachments/반응형%20웹/Untitled%201.png)

**유동형 그리드**는 그리드의 폭을 고정 값이 아닌 em 또는 %의 값으로 설정하는 것을 말한다. 즉, 가로 폭길이의 변화에 따라서 컬럼의 크기가 상대적으로 변한다.

다음은 간단한 유동형 그리드 예제이다. 자식 요소의 width 값을 고정 값이 아닌 %값으로 주어 전체 가로길이에 따라 자식 요소의 width가 유동적으로 변하게 한다.

![Untitled](attachments/반응형%20웹/Untitled%202.png)

가로 폭에 반응하기 때문에 레이아웃에 변화가 없는 모바일에서는 큰 효과를 볼 수 없다.

# 유동형 레이아웃 (Liquid Layouts)

**유동형 레이아웃**은 미디어 쿼리를 사용하여 일정 크기가 되면 레이아웃 구조를 바꾸어주는 방법을 말한다.

![Untitled](attachments/반응형%20웹/Untitled%203.png)

유동형 레이아웃은 특정한 레이아웃 구조가 있는 것은 아니지만 여러 패턴이 존재한다.

## LukeW 5가지 패턴

**Mostly Fluid**

- 유동형 그리드를 사용하여 레이아웃을 유지한다.
- 다만 가장 작은 화면에서는 수직으로 컬럼을 세운다.

![Untitled](attachments/반응형%20웹/Untitled%204.png)

**Column Drop**

- 화면이 작아짐에 따라 부차적인 컬럼을 아래로 떨어뜨린다.
- 대부분의 컬럼 폭은 화면 크기가 달라져도 크게 변하지 않는다.

![Untitled](attachments/반응형%20웹/Untitled%205.png)

**Layout Shifter**

- 다양한 기기에 따라 각기 다른 레이아웃을 보여준다.
- 복잡하고 많은 작업이 필요하지만 혁신적인 디자인을 담을 수 있다는 장점이 있다.

![Untitled](attachments/반응형%20웹/Untitled%206.png)

**Tiny Tweaks**

- 하나의 컬럼을 사용한다.
- 주로 글 내용을 중시할 때 쓰인다.

![Untitled](Untitled%207.png)

**Off Canvas**

- 큰 화면에서는 모든 컬럼들을 보여주고 화면이 작아질수록 컬럼을 숨긴다.
- 숨겨져 있는 컬럼은 필요할 때만 접근하도록 한다.

# 유연한 이미지

- 이미지 스타일의 **max-width를 100%**로, **height를 auto**로 설정한다.
- 화면 크기에 따라 이미지 크기도 유연하게 변한다.
- 하지만 모바일에서 봤을 때 작은 이미지면 충분한 작업을 해상도가 높은 이미지를 가져와 단순히 크기만 줄여 자원 낭비를 한다는 단점이 있다.
