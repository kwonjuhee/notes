
## 얕은 비교 vs 깊은 비교

- 얕은 비교(shallow compare) : primitive 타입은 값이 동일한지 비교하고 객체 타입은 참조만 비교한다.
- 깊은 비교(deep compare) : 객체의 경우에도 값으로 비교한다.

```js
// shallow
const obj1 = { a: 1, b: 2 };
const obj2 = { a: 1, b: 2 };

console.log(obj1 === obj2); // false
```

```js
// deep
const obj1 = { a: 1, b: 2 };
const obj2 = { a: 1, b: 2 };

console.log(JSON.stringify(obj1) === JSON.stringify(obj2)); // true
```

React에서는 기본적으로 얕은 비교를 사용하여 비교 연산을 수행한다.

## Strict Equality vs Loose Equality

https://developer.mozilla.org/en-US/docs/Web/JavaScript/Equality_comparisons_and_sameness

- Loose Equality (`==`) : type conversion을 수행하여 두 대상을 비교한다.
- Strict Equality (`===`) : type conversion 없이 같은 타입에 같은 값인 경우만 동일하다고 간주한다.
	- 객체를 비교하는 경우 같은 메모리 참조를 갖는지 확인한다.
	- `Object.is`는 -0과 0 비교, Nan 비교를 제외하면 `===`와 같은 결과를 갖는다.

기본적으로 Strict Equality를 검사한다.

## 비교 연산 사용처

### props 업데이트 검사

React에서 업데이트가 발생하면 해당 컴포넌트의 props 변경 여부를 확인한다. 이때 `oldProps === newProps` 연산을 사용하여 참조 값 비교를 통해 변경 여부를 판단한다.

```js
function beginWork(
  current: Fiber | null,
  workInProgress: Fiber,
  renderExpirationTime: ExpirationTime
): Fiber | null {
  const updateExpirationTime = workInProgress.expirationTime

  // 1. 컴포넌트 마운트 여부 확인
  if (current !== null) {
    const oldProps = current.memoizedProps
    const newProps = workInProgress.pendingProps

    // 2. ✅ 컴포넌트 호출 대상 판단 1
    if (oldProps !== newProps) {
      didReceiveUpdate = true

    // 2. 컴포넌트 호출 대상 판단 3
    } else if (updateExpirationTime < renderExpirationTime) {
      didReceiveUpdate = false

      // 더이상 Work를 진행하지 않고 자식의 current를 복제한 workInProgress만 만들어 반환
      return bailoutOnAlreadyFinishedWork(
        current,
        workInProgress,
        renderExpirationTime
      )

    // 2. 컴포넌트 호출 대상 판단 3
    } else {
      didReceiveUpdate = false
    }

  // 1. 컴포넌트 마운트 여부 확인
  } else {
    didReceiveUpdate = false
  }
  
  workInProgress.expirationTime = NoWork

  // fiber에 맞는 재조정 작업 라우팅
  switch (workInProgress.tag) {
    /*...*/
  }
}
```

### state 업데이트 검사

업데이트가 발생하면 컴포넌트를 호출한 후 state의 변경 여부를 확인한다. 이때 `Object.is` 연산을 사용한다.

```js
// https://github.com/facebook/react/blob/v16.12.0/packages/react-reconciler/src/ReactFiberHooks.js#L808

if (!is(newState, hook.memoizedState)) {
  markWorkInProgressReceivedUpdate() // didReceiveUpdate = true;
}
```

> 🔎 `didReceiveUpdate`는 컴포넌트의 props 또는 state 변경 여부를 나타내는 변수이다. 이를 통해 props, state 모두 변경되지 않았음이 확인된다면 work를 끊어주고 재조정 작업을 건너뛸 수 있다.

### memo 컴포넌트의 props 비교

memo 컴포넌트라면 컴포넌트를 호출하기 전에 props 변경 여부를 확인한다. 이때 `shallowEqual` 함수를 통해 비교한다.

```js
// https://github.com/facebook/react/blob/v16.12.0/packages/react-reconciler/src/ReactFiberBeginWork.js#L476
function updateSimpleMemoComponent(current, nextProps,...){
  /*...*/
  const prevProps = current.memoizedProps;
  if (shallowEqual(prevProps, nextProps)) {
    didReceiveUpdate = false;
    if (updateExpirationTime < renderExpirationTime) {
      return bailoutOnAlreadyFinishedWork(...);
    }
  }
  
  return updateFunctionComponent(
    current,
    workInProgress,
    Component,
    nextProps,
    renderExpirationTime,
  );
}
```

### shallowEqual

key를 반복(iterate)하여 shallow equality 검사를 수행한다. 중첩된 객체가 동일한 참조를 갖는지 검사할 수 있음.
- 엄격하게 동일(strictly equal)하지 않은 값이 있을 경우 false를 반환
- 모든 key의 값이 엄격하게 같으면 true를 반환

```js
// https://github.com/facebook/react/blob/8e2bde6f2751aa6335f3cef488c05c3ea08e074a/packages/shared/shallowEqual.js
function shallowEqual(objA: mixed, objB: mixed): boolean {

  // 1. 동일한 객체를 참조하는지 검사
  if (is(objA, objB)) {
    return true;
  }

  // 2. 둘 중 하나만 null 객체인 경우
  if (
    typeof objA !== 'object' ||
    objA === null ||
    typeof objB !== 'object' ||
    objB === null
  ) {
    return false;
  }

  // 3. 동일한 key 개수를 갖고 있는지
  const keysA = Object.keys(objA);
  const keysB = Object.keys(objB);

  if (keysA.length !== keysB.length) {
    return false;
  }

  // 4. 각 key의 값이 동일한지
  // Test for A's keys different from B.
  for (let i = 0; i < keysA.length; i++) {
    const currentKey = keysA[i];
    if (
      !hasOwnProperty.call(objB, currentKey) ||
      !is(objA[currentKey], objB[currentKey])
    ) {
      return false;
    }
  }

  return true;
}

export default shallowEqual;
```
