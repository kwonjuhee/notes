
React의 `cache` 함수는 React 18 버전에서 도입된 기능으로, 주로 서버 컴포넌트(Server Components)와 관련된 최적화를 위해 사용됩니다. **`cache`** 함수는 함수를 인자로 받아 그 함수를 메모이제이션된 새로운 함수를 반환합니다. 반환된 함수는 이전에 호출된 인자와 결과를 캐시하여, 같은 인자로 다시 호출될 때는 캐시된 결과를 반환합니다. 이를 통해 같은 인자로 함수를 반복 호출할 때 중복된 연산을 방지할 수 있습니다.

`cache` 함수의 주요 목적은 다음과 같습니다:

1. **중복 계산 방지**: 동일한 입력 값에 대해 함수가 여러 번 호출되는 경우, 이전에 계산된 결과를 재사용하여 중복 계산을 방지합니다. 이는 성능을 향상시키는 데 큰 도움이 됩니다.
    
2. **메모이제이션**: 함수의 결과를 메모리 내에 저장해 두고, 같은 입력 값이 다시 들어왔을 때 저장된 결과를 반환합니다. 이는 메모이제이션 패턴을 따르는 것입니다.
    
3. **서버 컴포넌트와의 통합**: 서버 컴포넌트는 서버에서 렌더링되며, 클라이언트로 전송되기 전에 서버에서의 계산 결과를 캐싱할 수 있습니다. 이를 통해 클라이언트에서 불필요한 계산을 줄일 수 있습니다.

### 사용 예시

아래는 `cache` 함수를 사용하는 간단한 예시입니다:

```jsx
import { cache } from 'react';

function expensiveCalculation(input) {
  // 매우 비용이 많이 드는 계산
  return input * 2;
}

const cachedCalculation = cache(expensiveCalculation);

function MyComponent() {
  const result = cachedCalculation(10);
  
  return <div>Result: {result}</div>;
}
```

이 예시에서 `expensiveCalculation` 함수는 매우 비용이 많이 드는 계산을 수행한다고 가정합니다. `cache` 함수를 사용하여 이 계산 결과를 캐싱하면, 동일한 입력 값에 대해 함수가 여러 번 호출되더라도 처음 계산된 결과를 재사용합니다.

### 주요 특징

- **캐시 무효화**: `cache` 함수는 내부적으로 캐시를 관리하며, 입력 값이 변경되면 자동으로 캐시를 무효화하고 다시 계산합니다.
    
- **서버 사이드 렌더링(SSR) 지원**: 서버 컴포넌트와 함께 사용할 때, 서버에서 계산된 결과를 클라이언트로 전송해 클라이언트에서의 계산을 줄일 수 있습니다.
    
- **간단한 API**: `cache` 함수는 간단한 API를 제공하여 함수형 컴포넌트 내에서 쉽게 사용할 수 있습니다.

`cache` 함수는 주로 성능 최적화를 위한 도구로, 특히 서버 컴포넌트와 함께 사용할 때 큰 이점을 제공합니다. 이를 통해 동일한 입력 값에 대해 중복 계산을 방지하고, 서버 사이드 렌더링 시 클라이언트의 부담을 줄일 수 있습니다.
