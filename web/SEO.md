## meta tag

### `title`

- 제목
- 브라우저 탭에 노출되는 제목
- 너무 긴 텍스트를 사용하거나 모든 페이지 title에 단일한 제목을 사용하지 않아야 한다.

### `description`

- 해당 페이지의 간단한 설명
- 대부분의 사용자는 이를 통해 해당 웹 페이지에 자신이 찾고 있는 정보가 있는지 판단한다.

### `robots`

- 웹 페이지 별로 검색 로봇의 접근 여부를 설정
https://developers.google.com/search/docs/crawling-indexing/robots-meta-tag?hl=ko

## open graph tag

- 웹 페이지의 링크가 공유될 때 어떻게 노출될지를 정의한다.
- 검색 상위 노출을 위한 품질 평가에도 영향을 준다.

- `og:title` : 웹페이지 제목
- `og:description` : 웹페이지 상세 설명
- `og:image` : 썸네일 (권장 사이즈 1200x630)
- `og:type` : 웹페이지 유형
- `og:url` : 웹페이지 주소
