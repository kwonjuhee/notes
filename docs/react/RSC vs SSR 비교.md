## RSC 장점

### 컴포넌트 단위의 렌더링 전략 설계

- Next.js는 top level 페이지 단위의 서버 사이드 렌더링을 지원
- RSC를 통해 컴포넌트 단위의 서버 사이드 렌더링이 가능해짐
- 컴포넌트별로 렌더링 전략을 설계할 수 있어 더 효율적인 렌더링이 가능해진다.

### 클라이언트 번들 크기 개선

- 서버 컴포넌트의 가장 큰 장점
- SSR은 html을 브라우저에 전달하여 LCP, FCP 향상에는 도움이 되지만 모든 코드가 번들에 포함되기 때문에 TTI가 기존 spa와 동일
- RSC는 번들에 포함되지 않고 json 형식의 직렬화된 정보를 브라우저에 제공하기 때문에 매우 빠른 TTI를 보여준다.
