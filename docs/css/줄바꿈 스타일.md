- 텍스트가 콘텐츠 박스를 오버플로우할 때 줄바꿈(line breaks)이 발생한다.
- 줄바꿈 스타일은 언어의 분류에 따라 제어한다.


## 언어의 분류

| 용어 | 설명 |
| --- | --- |
| CJK | Chinese-Japanes-Korean을 통틀어 이르는 말 (공통적으로 한자의 영향을 받음) |
| Non-CJK | CJK를 제외한 나머지 언어로 숫자, 영어, 베트남어 등을 지칭 |

- CJK 언어는 음절이나 문자 경계로 줄바꿈
- Non-CJK 언어는 공백 경계(단어 단위)로 줄바꿈하기 때문에 텍스트가 연속되는 경우 콘텐츠 오버플로우가 발생할 수 있따.


## 줄바꿈 스타일 속성

| 속성            | 설명                                                                                           | 값                            |
| ------------- | -------------------------------------------------------------------------------------------- | ---------------------------- |
| word-break    | 텍스트가 오버플로우될 때 줄을 바꿀지 결정                                                                      | normal, break-all, keep-all  |
| overflow-wrap | 어떤 문자가 오버플로우되지 않도록 단어 마디 안에서 줄을 바꿀지 결정 (`word-wrap`은 `overflow-wrap`의 비표준 속성으로 동일한 방식으로 작동함) | normal, break-word, anywhere |

### word-break

- `normal` (default)
	- 언어별 규칙에 따라 줄바꿈 발생
- `break-all`
	- 어떠한 문자 사이에서도 줄바꿈 발생 가능
	- Non-CJK 텍스트가 CJK 텍스트처럼 줄바꿈
- `keep-all`
	- 단어 내 줄바꿈 불가
	- CJK 텍스트가 Non-CJK 텍스트처럼 줄바꿈

>  🔎`break-word` (deprecated) : `overflow-wrap: anywhere`과 `word-break: normal`을 합친 것과 같은 효과를 갖는다.


### overflow-wrap / word-wrap

분리할 수 없는 문자열이 너무 길어 블록에 맞지 않는 경우 

- `normal` (default)
	- 허용된 중단점에서만 줄바꿈 가능
- `anywhere`
	- 오버플로우를 방지하기 위해 긴 단어나 URL과 같이 분리할 수 없는 문자열도 임의의 지점에서 줄바꿈을 허용
	- min-content 고유 크기를 계산할 때 고려됨
- `break-word`
	- `anywhere`와 동일하게 중단할 수 없는 문자열도 임의의 지점에서 줄바꿈을 허용
	- min-content 고유 크기를 계산할 때 고려하지 않음

### `word-break: break-all` + `overflow-wrap: break-word`

`word-break: break-all`만 사용하면 연속된 특수문자의 경우 브라우저, 버전, 문자에 따라 줄바꿈이 적용되지 않는 경우가 있다. 이런 경우에 `word-break: break-all`와 `overflow-wrap: break-word`를 함께 사용해야 한다.
