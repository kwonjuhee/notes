# 시맨틱 태그 사용 이유

- 검색엔진최적화 (SEO)
    - 검색엔진은 태그를 기반으로 페이지 내 검색 키워드의 우선순위를 판단한다.
    - 제목 h1~h6, 중요한 단어는 strong or em 등 의미에 맞는 올바른 태그를 사용하는 것이 중요하다.
- 스크린 리더 사용자가 페이지를 탐색할 때 도움이 된다.
- 의미가 있는 요소는 개발자 모두에게 명확한 의미를 전달한다.
- 개발자 입장에서 가독성이 높아지고 유지 보수가 쉬워진다.

# 시맨틱 태그를 정하는 기준

- 채워질 데이터를 가장 잘 설명하고 나타내는 요소를 선택한다.
- 스타일 기반이 아니라 채워질 데이터를 기반으로 결정한다.
    - 어떻게 보여야 하는지는 전적으로 CSS의 책임이다.

# 시맨틱 태그 살펴보기

`header`

- 페이지의 제목이나 대표 이미지 같은 소개 내용
- heading 태그, 로고, 아이콘, 저작권 정보, 검색 양식 등을 포함한다.
- `<body>`의 하위에서는 웹 페이지의 전체 헤더로, `<article>` `<section>`의 하위에서는 해당 영역의 헤더로 사용될 수 있다.

`nav`

- 메뉴, 목차

`aside`

- 기본 콘텐츠와
- 사이드바

`main`

- 지배적인 콘텐츠 영역
- 페이지당 하나만 사용

`section`

- 문서의 독립적인 영역으로 `<article>`과 유사하지만 페이지의 부분을 그룹화하는데 유용하게 사용된다.
- 섹션에는 제목이 있는 것이 일반적

`article`

- 요소 자체로 의미가 있는 웹 사이트의 부분이며 독립적으로 재사용되도록 의도된 문서
- 게시물, 잡지, 신문 기사, 블로그 작성글, 제품 카드, 대화형 위젯 등

`footer`

- 작성자에 대한 정보, 저작권, 관련 문서에 대한 링크 등

`strong` / `em`

- 강조되는 텍스트
