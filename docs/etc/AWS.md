## S3 (Simple Storage Service)

- 언제 어디든지 원하는 양의 데이터를 저장하고 검색하는데 사용할 수 있는 간단한 웹 서비스 인터페이스가 있다.

- REST 인터페이스를 통해 저장/삭제/조회가 가능하다.
- 주로 이미지 파일, 정적 리소스 등을 S3에 올려놓고 사용한다.
- 데이터 유실 가능성이 거의 존재하지 않는다.

## EC2 (Elastic Compute Cloud)

- AWS에서 제공하는 클라우드 컴퓨팅 서비스로 하나의 EC2 인스턴스는 한 대의 컴퓨터를 의미한다.


## 인스턴스 생성하기

1. region 선택

2. 인스턴스 생성
	- 이름
	- IAM
	- 인스턴스 유형
	- 키 페어 : EC2에 ssh로 접근 제어하기 위해 키 페어를 사용
	- 스토리지

3. 보안그룹 설정
	- 보안그룹 규칙을 통해 EC2 인스턴스로 들어오고 나가는 트래픽을 세부적으로 제어함
	- 예를 들어 ssh 접속 포트인 22번 포트는 개발자 pc에서만 접근 가능하도록, 서비스 포트인 80 포트는 모두가 접근 가능하도록 설정 가능
	- 인바운드란 외부에서 인스턴스로 들어오는 요청으로 작성한 인바운드 규칙으로만 인스턴스에 접근이 가능하다. http, https, 사용할 포트 열기
	- 아웃바운드란 인스턴스에서 외부로 나가는 트래픽으로 아웃바운드 규칙은 디폴트로 모두 허용이 되어 있다.
	- 소스
		-  사용자 지정 : IP 또는 CIDR로 특정 소스에 대한 권한 제어가 가능
		- 위치 무관 : 모두 허용
		- 내 IP : 현재 접속중인 IP만 등록


ssh 명령어

`ssh -i {pem키 경로} ubuntu@{인스턴스 ip주소}`
