```tsx
    /* This won't render anything ✅ */
    <>{false && <div>👋</div>}</>

    /* This will render 0 😡 */
    <>{0 && <div>👋</div>}</>

    /* This won't render anything ✅ */
    <>{""  && <div>👋</div>}</>

    /* This won't render anything ✅ */
    <>{null && <div>👋</div>}</>

    /* This won't render anything ✅ */
    <>{undefined && <div>👋</div>}</>

    /* This will render NaN 😡 */
    <>{NaN && <div>👋</div>}</>
```

## 삼항 연산자 사용

```tsx
    /* This won't render anything ✅ */
    <>{0 ? <div>👋</div> : null}</>

    /* This won't render anything ✅ */
    <>{NaN ? <div>👋</div> : null}</>

```

## falsy 값을 Boolean으로 변환

```tsx
    /* This won't render anything ✅ */
    <>{Boolean(0) && <div>👋</div>}</>

    /* This won't render anything ✅ */
    <>{Boolean(NaN) && <div>👋</div>}</>

    /* This won't render anything ✅ */
    <>{!!0 && <div>👋</div>}</>

    /* This won't render anything ✅ */
    <>{!!NaN && <div>👋</div>}</>
```
