앱이 커지면 번들 사이즈 또한 커지게 되므로 초기 렌더링이 늦어지는 문제가 발생한다.

코드 분할(Code Splitting)은 런타임에 여러 번들을 동적으로 만들고 불러오는 것으로 번들러가 지원하는 기능이다. 코드 분할은 여러분의 앱을 “지연 로딩” 하게 도와주고 앱 사용자에게 획기적인 성능 향상을 하게 한다. 앱의 코드 양을 줄이지 않고도 사용자가 필요하지 않은 코드를 불러오지 않게 하며 앱의 초기화 로딩에 필요한 비용을 줄여준다.
