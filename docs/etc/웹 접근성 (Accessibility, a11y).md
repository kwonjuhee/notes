
- 웹 접근성(별칭: a11y)은 모든 신체적 한계, 환경적 한계를 고려하여 모두가 사용할 수 있도록 웹 사이트를 디자인, 개발하는 것을 의미한다.
    - 장애, 노령, 여러 기기 환경 등
    - 보조과학기술(assistive technology)이 웹 페이지를 해석할 수 있어야함
- 장애인 차별 금지법에도 명시되어 있는 사항으로 의무적으로 지켜야 한다.

# 표준 및 지침

### **WAI -ARIA**

W3C에서 설립한 WAI(Web Accessibility Initiative)에서 제공하는 가이드라인

[WAI-ARIA Overview](https://www.w3.org/WAI/standards-guidelines/aria/)

### 1. 속어, 약어 사용 지양하기

- 모두가 해당 정보를 이해할 수 있어야한다.
- 전문 용어, 속어, 비속어 사용을 지양한다.
- 약어는 모두가 이해할 수 있도록 최대한 풀어서 작성한다.

### 2. HTML을 시맨틱하게 작성하기

- 시맨틱 HTML은 스크린 리더가 글의 내용을 파악할 때 도움을 준다.
    - 제목 요소를 기준으로 목차를 만든다.
    - 이전, 이후 문단으로 이동하는 기능을 제공한다.
    - 나눠진 문단을 기준으로 속도를 조절한다.
    - 각 요소의 내용에 맞게 읽는 방식을 조절한다.
    - 등등
- 콘텐츠의 제목과 단락을 명확하게 구분하기 위해 HTML을 시맨틱하게 작성하자!

### 3. 키보드 동작 제공하기

- 모든 웹 어플리케이션은 키보드만 사용하여 모든 동작을 할 수 있어야 한다.
- 탭 키를 통해 콘텐츠를 탐색할 수 있도록 한다. 이때 원하는 콘텐츠로 건너뛸 수 있도록 하여 탐색 속도를 증진시켜주면 좋다.
- button, input, select 등의 요소를 사용하지 않고 div로 비슷하게 구현해 사용하는 경우 기본 요소들이 제공하는 키보드 동작을 모두 사용하지 못한다.
    - 엔터 키, 탭 키를 누를 때
    - select 태그에서 화살표로 아이템 선택하기
- 스크린 리더는 해당 요소가 선택해야 하는 요소인지, 이벤트를 발생시키는 요소인지 파악하지 못한다.

따라서 추가적인 속성을 제공하여 사용 목적과 유사하게 만들어야 한다!

| 속성 | 의미 |
| --- | --- |
| role | 해당 요소의 원래 목적을 작성한다. div 요소에 role=button을 작성하면 스크린 리더가 해당 요소를 버튼으로 인식한다. |
| tab-index | 해당 요소를 탭 키로 도달하게 한다. 탭 키로 이동할 다음 키보드 위치를 지정한다. |
| 키보드 이벤트 리스너 추가 | 엔터 키, 탭 키, 화살표 키 등 키보드로 동작할 수 있게끔 이벤트 리스너를 추가해준다. |

### 4. focus 항목 나타내기

- 항목에 focus가 된다면 시력이 있는 사용자들을 위해 윤곽선이 나타나야 한다.
    - ⚠️ `outline: 0`은 포커스 윤곽선을 제거하는 CSS이므로 다른 윤곽선으로 대체할 때만 사용해야 한다.

### 5. 멀티미디어 요소에 접근성 부여하기

- 스크린 리더는 텍스트를 읽어주지만 이미지, 동영상, 오디오와 같은 멀티미디어 요소에는 접근할 수 없다.
- `alt` 속성을 사용하여 이미지가 시각적으로 어떤 모습인지 올바르게 전달해야 한다.
    - 해당 속성이 없다면 `“{이미지 파일 이름}, image”` 이렇게 읽음

### 6. 숨김 콘텐츠를 잘 처리하기

`aria-hidden="true"`

- 시각적으로는 보이지만 스크린 리더가 읽지 않도록 처리한다.
- 눈에 보이는 장식적 요소(아이콘 등)에 사용할 수 있다.
- focusable한 요소에 사용하면 안된다.

`aria-label`

- 눈에 보이지 않더라도 읽어주길 원하는 요소
- 예를 들면 아이콘만으로 구성된 버튼이 어떤 버튼인지 나타낼 때 사용할 수 있다.

### 7. 접근성 있는 폼

- \<input>과 \<textarea> 같은 모든 HTML 폼 컨트롤은 구분할 수 있는 라벨이 필요하다. 스크린 리더를 사용하는 사용자를 위해 자세한 설명이 담긴 라벨을 제공해야 한다.
- 스크린 리더 사용자들을 위해 오류 안내하기
