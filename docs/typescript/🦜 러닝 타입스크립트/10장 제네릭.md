
제네릭은 **호출하는 방식에 따라 다양한 타입으로 작동하도록 의도하는 방법**

```tsx
function identity(input) {
  return input;
}

identity("abc");
identity(123);
identity({});
```

위의 예제에서 input을 any로 선언한다면 반환 타입 역시 any가 된다. input이 모든 입력을 허용한다면 input 타입과 함수 반환 타입 간의 관계를 말할 수 있는 방법이 필요하다.

타입스크립트는 제네릭을 사용해 타입 간의 관계를 알아낸다.

**제네릭 타입 매개변수**

- 타입스크립트에서 함수와 같은 구조체는 제네릭 타입 매개변수를 원하는 수만큼 선언할 수 있다.
- 제네릭 타입 매개변수는 구조체의 사용법에 따라 타입이 결정된다.
- 제네릭 타입 매개변수는 구조체의 각 인스턴스에 대해 서로 다른 **타입 인수**를 함께 제공할 수 있고 이는 인스턴스 내에서 일관성을 유지한다.
- 타입 매개변수는 전형적으로 T나 U같은 단일 문자 이름 또는 Key와 Value 같은 파스칼 케이스 이름을 갖는다.

## 제네릭 함수

- 매개변수 괄호 앞 `<>`에 타입 매개변수를 추가해 함수를 제네릭으로 만들 수 있다.
- 해당 타입 매개변수를 함수의 본문 내부의 매개변수 타입 애너테이션, 반환 타입 애너테이션, 타입 애너테이션에서 사용할 수 있다. (사실 컴파일러가 강요)
- 다음 identity 함수는 input 매개변수에 대한 타입 매개변수 T를 선언한다. 이를 통해 타입스크립트는 함수의 반환 타입이 T임을 유추하는데 호출될 때마다 T에 대한 다른 타입을 유추할 수 있다.
    
    ```tsx
    function identity<T>(input: T) {
      return input;
    }
    
    const numeric = identity("me"); // 타입 "me"
    const stringy = identity(123); // 타입 123
    ```
    
- 화살표 함수의 제네릭 선언
    
    ```tsx
    /** 화살표 함수 */
    const identity = <T>(input: T) => input;
    ```
    
- 타입 매개변수를 추가하면 타입 안정성을 유지하고 any 타입을 피하면서 다른 입력과 함께 재사용할 수 있다.

### 명시적 제네릭 호출 타입

- 제네릭 함수를 호출할 때 타입스크립트는 함수가 호출되는 방식에 따라 타입 인수를 유추한다.
    - 전달하는 인수에 따라 컴파일러가 T의 값을 자동으로 정하게 하는 것
    
    ```jsx
    let output = identity("myString"); //출력 타입은 'string'입니다.
    ```
    
- 인수 추론은 코드를 간결하고 가독성있게 하는 데 있어 유용하지만 때로는 타입 인수를 해석하기 위해 타입스크립트에 알려줘야 하는 함수 호출 정보가 충분하지 않을 수도 있다.
    - 타입 인수를 알 수 없는 제네릭 구문이 다른 제네릭 구문에 제공된 경우 주로 발생
- 다음 예제는 타입스크립트가 Input이 무엇이 되어야할지 알아낼 수 없어 기본 값이 unknown으로 설정된다.
    
    ```tsx
    // callback의 매개변수 타입은 logWrapper의 타입 매개변수 Input
    function logWrapper<Input>(callback: (input: Input) => void) {
      return (input: Input) => {
        console.log("Input", input);
        callback(input);
      };
    }
    
    // 타입 (input: unknown) => void
    logWrapper((input) => {
      console.log(input.length); // Error: length 속성은 unknown에 존재할 수 없다.
    });
    ```
    
- logWrapper 호출시 **callback의 매개변수 타입을 명시적으로 선언**하면 타입스크립트가 타입 인수를 유추할 수 있다.
    
    ```tsx
    // 타입 (input: string) => void
    logWrapper((input: string) => {
      console.log(input.length);
    });
    ```
    
- 해당 타입 인수가 무엇인지 명시적으로 알려주는 **명시적 제네릭 타입 인수**를 사용해 함수를 호출할 수 있다.
    - 타입스크립트는 제네릭 호출에서 타입 검사를 수행하여 매개변수가 타입 인수(`<>`)로 제공된 것과 일치하는지 확인한다.
    -  명시적 타입 인수는 항상 지정할 수 있지만 필요할 때만 지정한다.
    
    ```tsx
    // Input 제네릭을 위한 명시적 타입 string과 함께 제공
    // 타입스크립트는 제네릭 타입 Input의 콜백 매개변수 input을 string 타입으로 유추
    
    // 타입 (input: string) => void
    logWrapper<string>((input) => {
      console.log(input.length);
    });
    
    logWrapper<string>((input: boolean) => {
      // Error: Argument of type '(input: boolean) => void' is not assignable to parameter of type '(input: string) => void'.
    });
    ```

- 타입 인수와 매개변수 타입 중 하나만 명시적으로 지정해도 된다.
    
    ```tsx
    logWrapper<string>((input: string) => { /** ... */ });
    ```
    

### 다중 함수 타입 매개변수

- 여러 개의 타입 매개변수는 쉼표로 구분해 함수를 정의한다.
    - 제네릭 구조체에서 두 개 이상의 타입 매개변수를 사용하지 않는 것이 좋다. 코드를 읽고 이해하는 것이 어려워지기 때문에.
- 함수 호출시 **각 타입 매개변수에 대한 자체 값 집합**을 확인할 수 있다.
- 함수가 여러 개의 타입 매개변수를 선언하면 **해당 함수 호출시 제네릭 타입을 모두 명시적으로 선언하지 않거나 모두 선언해야 한다.** (타입스크립트는 아직 제네릭 호출 중 일부 타입만을 유추하지 못한다)
    
    ```tsx
    function makePair<Key, Value>(key: Key, value: Value) {
      return { key, value };
    }
    
    // 타입 인수가 둘 다 제공되지 않음
    makePair("abc", 123);
    
    // 타입 인수가 둘 다 제공됨
    makePair<string, number>("abc", 123); // 타입 { key: string; value: number }
    makePair<"abc", 123>("abc", 123); // 타입 { key: "abc"; value: 123 }
    
    // Error
    makePair<string>("abc", 123);
    ```
    

## 제네릭 인터페이스

- 인터페이스 이름 뒤 `<>`에 타입 매개변수를 선언해 인터페이스를 제네릭으로 선언할 수 있다.
- 다음 Box 선언은 속성에 대한 T 타입 매개변수가 있다. 타입 인수를 전달하여 Box로 선언된 객체를 생성하면 inside의 T 속성이 해당 타입 인수와 일치된다.

```tsx
interface Box<T> {
  inside: T;
}

let stringBox: Box<string> = {
  inside: "abc",
}

let numberBox: Box<number> = {
  inside: 123,
}

let incorrectBox: Box<number> = {
  inside: false, // Error: Type 'boolean' is not assignable to type 'number'.
}
```

### 유추된 제네릭 인터페이스 타입

- 제네릭 인터페이스의 타입 인수는 사용법에서 유추할 수 있다.
- 선언된 위치에 제공된 값의 타입에서 타입 인수를 유추한다.

```tsx
interface LinkedNode<Value> {
  next?: LinkedNode<Value>;
  value: Value;
}

// 타입 매개변수 Value를 선언한다음 Value를 node 매개변수로 사용한다.
function getLast<Value>(node: LinkedNode<Value>): Value {
  return node.next ? getLast(node.next) : node.value;
}

// 타입스크립트는 인수로 전달된 값의 타입에 따라 Value를 유추한다.
// 유추된 Value 타입 인수: Date
let lastDate = getLast({
  value: new Date(),
});

// 유추된 Value 타입 인수: string
let lastFruit = getLast({
  next: {
    value: "banana"
  },
  value: "apple"
});

// 유추된 Value 타입 인수: number
let lastMismatch = getLast({
  next: {
    value: 123
  },
  value: false // Error: type 'boolean' is not assignable to type 'number'
});
// 인터페이스 정의 순서에 따라 우선순위가 변하는듯
```

- 인터페이스가 타입 매개변수를 선언하는 경우 해당 인터페이스를 참조하는 모든 **타입 애너테이션은 이에 상응하는 타입 인수를 제공해야 한다.**

```tsx
interface CrateLike<T> {
  contents: T;
}

let missingGeneric: CrateLike = {
  contents: "??" // Error: Generic type 'CrateLike<T>' requires 1 type argument(s).
}
```

## 제네릭 클래스

- 클래스도 나중에 멤버에서 사용할 임의의 수의 타입 매개변수를 선언할 수 있다.
- 다음 Secret 클래스는 Key와 Value 타입 매개변수를 선언한 다음 이를 멤버 속성, constructor 매개변수 타입, 메서드의 매개변수, 반환 타입으로 사용한다.

```jsx
class Secret<Key, Value> {
  key: Key;
  value: Value;

  constructor(key: Key, value: Value) {
    this.key = key;
    this.value = value;
  }

  getValue(key: Key): Value | undefined {
    return this.key === key ? this.value : undefined;
  }
}

const storage = new Secret(12345, "luggage"); // 타입 Secret<number, string>

storage.getValue(1987); // 타입 string | undefined
```

- 제네릭 인터페이스와 마찬가지로 클래스를 사용하는 타입 애너테이션은 해당 클래스의 제네릭 타입이 무엇인지를 타입스크립트에 나타내야 한다.

### 명시적 제네릭 클래스 타입

- 기본적으로 타입 인수를 유추한다. new Secret(12345, “luggage”)와 같이 함수 생성자에 전달된 매개변수의 타입으로부터 타입 인수를 유추할 수 있다면 타입스크립트는 유추된 타입을 사용한다.
- **타입을 유추할 수 없는 경우 타입 인수의 기본값은 unknown**이 된다.

```tsx
class CurriedCallback<Input> {
  #callback: (input: Input) => void;

  constructor(callback: (input: Input) => void) {
    this.#callback = (input: Input) => {
      console.log("Input", input);
      callback(input);
    }
  }

  call(input: Input) {
    this.#callback(input);
  }
}

// 타입 CurriedCallback<unknown>
new CurriedCallback((input) => {
  console.log(input.length); // Error
});
```

- **명시적 타입 인수의 타입 애너테이션**
    
    ```tsx
    // 타입 CurriedCallback<string>
    new CurriedCallback((input: string) => {
      console.log(input.length);
    });
    ```
    
- **명시적 제네릭 타입 인수를 제공**
    
    ```tsx
    // 타입 CurriedCallback<string>
    // Input 타입 매개변수가 string으로 해석된다.
    new CurriedCallback<string>((input) => {
      console.log(input.length);
    });
    ```
    

### 제네릭 클래스 확장

- 타입 스크립트는 extends 키워드 다음에 오는 기본 클래스에 대한 타입 인수를 유추하지 않는다.
- 제네릭 클래스를 기본 클래스로 사용하는 경우 기본 값이 없는 모든 타입 인수는 **명시적 타입 애너테이션을 사용해야 한다.**

```tsx
class Quote<T> {
  lines: T;

  constructor(lines: T) {
    this.lines = lines;
  }
}

class SpokenQuote extends Quote<string[]> {
  speak() {
    console.log(this.lines.join("\n"));
  }
}

new Quote("~~~").lines; // 타입: string
new Quote([1,2,3,4,5]); // 타입: number[]

new SpokenQuote([
  "~~~",
  "!!!",
]).lines; // 타입: string[]

new SpokenQuote([1,2,3,4,5]); // Error: Argument of type 'number' is not assignable to parameter of type 'string'.
```

- 제네릭 파생 클래스는 **자체 타입 인수를 기본 클래스에 전달할 수 있다.** 타입 이름은 일치하지 않아도 된다.
- 다음 AttributedQuote는 다른 이름의 Value 타입 인수를 기본 클래스 Quote\<T>에 전달한다.

```tsx
class Quote<T> {
  lines: T;

  constructor(lines: T) {
    this.lines = lines;
  }
}

class AttributedQuote<Value> extends Quote<Value> {
  speaker: string;

  constructor(value: Value, speaker: string) {
    super(value);
    this.speaker = speaker;
  }
}

new AttributedQuote("~~~", "!!!");
```

### 제네릭 인터페이스 구현

- 제네릭 클래스는 모든 필요한 매개변수를 제공함으로써 제네릭 인터페이스를 구현한다.
- 제네릭 인터페이스는 제네릭 기본 클래스를 확장하는 것과 유사하게 작동한다. 기본 인터페이스의 모든 타입 매개변수는 클래스에 선언되어야 한다.

```tsx
interface ActingCredit<Role> {
  role: Role;
}

// MoviePart 클래스는 ActingCredit 인터페이스의 Role 타입 인수를 string으로 지정
class MoviePart implements ActingCredit<string> {
  role: string;
  speaking: boolean;

  constructor(role: string, speaking: boolean) {
    this.role = role;
    this.speaking = speaking;
  }
}

const part = new MoviePart("aaa", true);

part.role; // 타입: string

// 타입 인수로 string을 제공함에도 불구하고 role이 boolean 타입이므로 타입 오류가 발생한다.
class IncorrectExtension implements ActingCredit<string> {
  role: boolean;
  // Error: Property 'role' in type 'IncorrectExtension' is not assignable to the same property in base type 'ActingCredit<string>'.
  // Type 'boolean' is not assignable to type 'string'.
}
```

### 메서드 제네릭

- 클레스 메서드는 클래스 인스턴스와 별개로 자체 제네릭 타입을 선언할 수 있다.
- 제네릭 클래스 메서드에 대한 각각의 호출은 각 타입 매개변수에 대해 다른 타입 인수를 갖는다.

```tsx
class CreatePairFactory<Key> {
  key: Key;

  constructor(key: Key) {
    this.key = key;
  }

  createPair<Value>(value: Value) {
    return { key: this.key, value };
  }
}

const factory = new CreatePairFactory("role"); // 타입: CreatePairFactory<string>

const numberPair = factory.createPair(10); // 타입: { key: string, value: number }

const stringPair = factory.createPair("sss"); // 타입: { key: string, value: string }
```

### 정적 클래스 제네릭

- 정적 멤버는 인스턴스 멤버와 구별되고 특정 인스턴스에 접근할 수 없다.
- 따라서 정적 클래스 메서드는 자체 타입 매개변수를 선언할 수 있지만 클래스에 선언된 어떤 타입 매개변수에도 접근할 수 없다.

```tsx
class BothLogger<OnInstance> {
  instanceLog(value: OnInstance) {
    console.log(value);
    return value;
  }

  // 클래스 인스턴스에 대해 OnInstance가 선언되었으므로 static 메서드는 OnInstance 인스턴스에 접근할 수 없다.
  static staticLog<OnStatic>(value: OnStatic) {
    let fromInstance: OnInstance;
    // Error: Static members cannot reference class type arguments.

    console.log(value);
    return value;  
  }
}

const logger = new BothLogger<number[]>;
logger.instanceLog([1, 2, 3]); // 타입: number[]

BothLogger.staticLog([false, true]); // 유추된 OnStatic 타입 인수: boolean[]

BothLogger.staticLog<string>("aaa"); // 유추된 OnStatic 타입 인수: string
```


## 제네릭 타입 별칭

```tsx
type Nullish<T> = T | null | undefined;
```

제네릭 타입 별칭은 일반적으로 **제네릭 함수의 타입을 설명하는 함수와 함께 사용**된다.

```tsx
type CreatesValue<Input, Output> = (input: Input) => Output;

// 타입 (input: string) => number
let creator: CreatesValue<string, number>;

creator = text => text.length; // Ok
creator = text => text.toUpperCase(); // Error: Type 'string' is not assignable to type 'number'.
```

### 제네릭 판별된 유니언

- 제네릭 타입과 판별된 유니언 타입을 함께 사용하면 재사용 가능한 타입을 모델링하는 훌륭한 방법을 제공할 수 있다.
- 데이터의 성공적인 결과 또는 오류로 인한 실패를 나타내는 제네릭 `Result` 타입 예시
    
    ```tsx
    type Result<Data> = FailureResult | SuccessfulResult<Data>;
    
    interface FailureResult {
      error: Error;
      succeeded: false;
    }
    
    interface SuccessfulResult<Data> {
      data: Data;
      succeeded: true;
    }
    
    function handleResult(result: Result<string>) {
      // succeeded 판별자를 이용해 성공 또는 실패 여부에 대한 결과 내로잉
      if (result.succeeded) {
        // result는 SuccessfulResult<string> 타입
        console.log(result.data);
      } else {
        // result는 FailureResult 타입
        console.log(result.error);
      }
    }
    ```
    

## 제네릭 제한자

### 제네릭 기본값

- 타입 매개변수 선언 뒤에 기본값을 지정할 수 있다.
- 제네릭 타입이 타입 애너테이션에 사용되거나 extends 또는 implements의 기본 클래스로 사용되는 경우에도 기본 값이 있다면 타입 인수를 제공하지 않아도 된다.
- 기본 값은 타입 인수가 명시적으로 선언되지 않고 유추할 수 없는 모든 후속 타입에 사용된다.

```tsx
interface Quote<T = string> {
  value: T;
}

let explicit: Quote<number> = { value: 123 };

let implicit: Quote = { value: "~~~" };

let mismatch: Quote = { value: 123 }; // Error: Type 'number' is not assignable to type 'string'.
```

- 동일한 선언 안의 앞선 타입 매개변수를 기본값으로 가질 수 있다.
    - 다음 KeyValuePair 타입은 Key와 Value 제네릭에 대해 다른 타입을 가질 수 있지만 기본적으로 동일한 타입을 유지한다.
    - Key는 기본값이 없기 때문에 여전히 유추 가능하거나 제공되어야 한다.
    
    ```tsx
    interface KeyValuePair<Key, Value = Key> {
      key: Key;
      value: Value;
    }
    
    // 타입: KeyValuePair<string, number>
    let allExplicit: KeyValuePair<string, number> = {
      key: "rating",
      value: 10,
    };
    
    // 타입: KeyValuePair<string, string>
    let oneDefaulting: KeyValuePair<string> = {
      key: "rating",
      value: "ten",
    };
    
    let firstMissing: KeyValuePair = {
      // Error: Generic type 'KeyValuePair<Key, Value>' requires between 1 and 2 type arguments.
      key: "rating",
      value: 10,
    };
    ```
    
- 기본 타입 매개변수는 선언 목록의 맨 마지막에 와야 한다.
    
    ```tsx
    function inTheEnd<First, Second, Third = number, Fourth = string>() {} // Ok
    
    function inTheMiddle<First, Second = boolean, Third = number, Fourth>() {}
    // Error: Required type parameters may not follow optional type parameters.
    ```
    

## 제한된 제네릭 타입

- 기본적으로 제네릭 타입에는 클래스, 인터페이스, 원싯값, 유니언, 별칭 등 모든 타입을 제공할 수 있지만 일부 함수는 제한된 타입에서만 작동해야 한다.
- 타입 매개변수가 타입을 확장해야 한다고 선언함으로써 제한할 타입을 지정할 수 있다. (별칭 타입에만 허용되는 작업)
- 타입 매개변수를 제한하는 구문: 매개변수 이름 extends 제한할 타입
- 다음 제네릭 함수는 length: number를 가진 모든 타입을 받아들이도록 하는 예시이다.
    
    ```tsx
    interface WithLength {
      length: number;
    }
    
    function logWithLength<T extends WithLength>(input: T) {
      return input;
    }
    
    logWithLength("~~~");
    
    logWithLength([false, true]);
    
    logWithLength({ length: 123 });
    logWithLength({ length: 123, a: 123});
    
    logWithLength(new Date());
    // Error: Argument of type 'Date' is not assignable to parameter of type 'WithLength'.
    // Property 'length' is missing in type 'Date' but required in type 'WithLength'.
    ```
    

### keyof와 제한된 타입 매개변수

- extends와 keyof를 함께 사용하면 타입 매개변수를 이전 타입 매개변수의 키로 제한할 수 있다.
- 또한 제네릭 타입의 키를 지정하는 유일한 방법

```tsx
function get<T, Key extends keyof T>(container: T, key: Key) {
  return container[key];
}

const roles = {
  favorite: "Fargo",
  others: ["Almost Famous", "Burn After Reading", "Nomadland"],
};

const favorite = get(roles, "favorite"); // string
const others = get(roles, "others"); // string[]

const missing = get(roles, "extras"); // Error: Argument of type '"extra"' is not assignable to parameter of type '"favorite" | "others"'.
```

- 다음과 같이 key 매개변수가 모든 keyof T라면 반환 타입은 container에 있는 모든 속성 값에 대한 유니언 타입이 된다.
- 이렇게 구체적이지 않은 함수 선언은 각 호출이 타입 인수를 통해 특정 key를 가질 수 있음을 타입스크립트에 나타낼 수 없다.

```tsx
function get<T>(container: T, key: keyof T) {
  return container[key];
}

const found = get(roles, "favorite"); // string | string[]
```


## Promise

- Promise는 요청 이후 결과를 받기까지 대기가 필요하며 대기중인 작업의 성공/실패에 따른 콜백(resolve/reject)을 등록하기 위한 메서드를 제공한다.
- 임의의 값 타입에 대해 유사한 작업을 나타내는 Promise의 기능은 제네릭과 자연스럽게 융합된다.
- Promise는 ts 타입 시스템에서 최종적으로 resolve된 값을 나타내는 단일 타입 매개변수를 가진 Promise 클래스로 표현된다.

### Promise 생성

- Promise 생성자는 단일 매개변수를 받도록 작성되며 해당 매개변수의 타입은 제네릭 타입 매개변수에 의존한다.
- 대략 이런식

```tsx
class PromiseLike<Value> {
  constructor(
    executor: (
      resolve: (value: Value) => void,
      reject: (reason: unknown) => void,
    ) => void
  ) { /* ... */ }
}
```

- 결과적으로 값을 resolve하는 Promise를 만들려면 Promise의 타입 인수를 명시적으로 선언해야 한다.
- 타입스크립트는 명시적 제네릭 타입 인수가 없다면 기본적으로 매개변수 타입을 unknown으로 가정한다. Promise 생성자에 타입 인수를 명시적으로 제공하면 타입스크립트가 결과로서 생기는 resolve된 타입을 이해할 수 있다.

```tsx
// 타입 Promise<unknown>
const resolveUnknown = new Promise((resolve) => {
  setTimeout(() => resolve("Done!"), 1000);
});

// 타입 Promise<string>
const resovleString = new Promise<string>((resolve) => {
  setTimeout(() => resolve("Done!"), 1000);
});
```

- then 메서드는 반환되는 Promise의 resolve된 값을 나타내는 새로운 타입 매개변수를 갖는다.

```tsx
const textEventually = new Promise<string>((resolve) => {
  setTimeout(() => resolve("Done!"), 1000);
});

const lengthEventually = textEventually.then(text => text.length);
```

### async 함수

- async 키워드를 사용해 선언한 함수는 모두 Promise를 반환한다.
- async 함수는 반환된 값이 Thenable(then 메서드가 있는 객체, 실제로는 거의 항상 Promise)이 아닌 경우 Promise.resolve가 호출된 것처럼 Promise로 래핑된다.

```tsx
// Promise<number>를 직접 반환
// 타입 (text: string) => Promise<number>
async function lengthAfterSecond(text: string) {
  await new Promise((resolve) => setTimeout(resolve, 1000));
  return text.length;
}

// 직접 number를 반환하기 때문에 Promise<number>를 반환하는 것으로 간주됨
// 타입 (text: string) => Promise<number>
async function lengthImmediately(text: string) {
  return text.length;
}
```

- 반환 타입을 명시하지 않아도 항상 Promise 타입이 된다.

```tsx
async function givesPromiseForString(): Promise<string> {
  return "Done!";
}

async function givesString(): string {
  return "Done!";
} // Error: The return type of an async function or method must be the global Promise<T> type.
```
