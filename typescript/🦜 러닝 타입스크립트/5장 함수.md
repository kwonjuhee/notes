
## 함수 매개변수

- 매개변수는 명시적인 타입 선언이 없으면 타입을 알 수 없다. 타입 선언이 없으면 any 타입으로 간주한다.
- 타입 애너테이션으로 타입 선언한다.

### 필수 매개변수

- 자바스크립트에서는 인수의 수와 상관없이 함수를 호출할 수 있지만 타입스크립트는 함수에 선언된 모든 매개변수가 필수라고 가정한다.
- 함수 호출시에 인수의 개수가 맞지 않으면 타입 오류 발생
- 인수를 넘기도록 강제하여 타입 안정성을 강화하는데 도움이 된다.

### 선택적 매개변수

- 인수를 넘길 필요가 없을 때도 있기 때문에 의도적으로 undefined를 사용할 수 있다. 타입 애너테이션에 ?를 추가하여 매개변수가 선택적임을 표시한다.
- 모든 선택적 매개변수는 마지막 매개변수여야 한다.

```tsx
function announceSong(song: string, singer?: string) {
	if (singer) { // 이 if문으로 인해 string 타으로 좁혀진다.
		console.log(`Singer: ${singer}`);
	}
}

announceSong("aaa");
announceSong("aaa", undefined);
announceSong("aaa", "bbb");
```

- 선택적 매개변수는 **암묵적으로 | undefined 유니언 타입이 추가**된다. 하지만 | undefined 유니언 타입 매개변수와는 다르다. 이는 값이 undefined일지라도 명시적으로 항상 제공되어야 한다.

```tsx
function announceSong(song: string, singer: string | undefined) { /** ... */ }

announceSong("aaa"); // Error: Expected 2 arguments, but got 1.
```

### 기본 매개변수

- **선택적 매개변수를 선언할 때 =와 값이 포함된 기본값을 제공할 수 있다.**
- 함수 내부에 암묵적으로 | undefined 유니언 타입이 추가된다.
- 기본값이 있고 **타입 애너테이션이 없는 경우 기본값을 기반으로 매개변수의 타입을 유추**한다. (변수 초기값과 마찬가지로)

```tsx
// rateSong 함수에서 rating은 number 타입으로 유추되고
// 함수를 호출하는 코드에서는 선택적 number | undefined가 된다.
function rateSong(song: string, rating = 0) { /** ... */ }

rateSong("aaa"); // ok
rateSong("aaa", 5); // ok
rateSong("aaa", undefined); // ok
```

### 나머지 매개변수

- 자바스크립트의 일부 함수는 임의의 수의 인수로 호출할 수 있도록 만들어진다.
- 나머지 인수는 모두 단일 배열에 저장되어야 하므로 타입 또한 배열로 선언

```tsx
function singAllTheSongs(singer: string, ...songs: string[]) { /** ... */ }
```

## 반환 타입

- **함수가 반환할 수 있는 가능한 모든 값을 이해하면 함수가 반환하는 타입을 알 수 있다.**
    
    ```tsx
    // 타입: (songs: string[]) => number
    function singSongs(songs: string[]) {
    	return songs.length;
    }
    ```
    
- 다른 값을 가진 여러 개의 반환문을 포함하고 있다면 **가능한 모든 반환 타입의 조합으로 유추**
    
    ```tsx
    // 타입: (songs: string[], index: number) => string | undefined
    function getSongAt(songs: string[], index: number) {
    	return index < songs.length
    		? songs[index]
    		: undefined;
    }
    ```
    

### 명시적 반환 타입

- 반환 타입을 명시적으로 선언하지 않는 것이 좋지만 유용할 때가 종종 있다.
    - 가능한 반환값이 많은 함수가 항상 동일한 타입의 값을 반환하도록 강제한다.
    - 타입스크립트는 재귀 함수의 반환 타입을 통해 타입을 유추하는 것을 거부한다.
    - 수백 개 이상의 타입스크립트 파일이 있는 매우 큰 프로젝트에서 타입 검사 속도를 높일 수 있다.
    
    ```tsx
    function singSongsRecursive(songs: string[], count = 0): number => {
    	return songs.length ? singSongsRecursive(songs.slice(1), count + 1) : count;
    }
    ```
    
- 함수의 반환문이 함수의 반환 타입으로 할당할 수 없는 값을 반환하는 경우 할당 가능성 오류 발생

## 함수 타입

- 함수를 값으로 전달하는 경우
- 콜백 매개변수를 설명할 때 자주 사용된다

```tsx
const songs = ["a", "b", "c"];

function runOnSongs(getSongAt: (index: number) => string) { /** ... */ }

function getSongAt(index: number) { /** ... */ }

runOnSongs(getSongAt); // ok

function logSong(song: string) { /** ... */ }

runOnSongs(logSong); // Error
```

### 함수 타입 괄호

- 유니언 타입으로 함수를 사용할 때 괄호로 함수 타입을 괄호로 묶어야 한다.

```tsx
// 타입은 string | undefined 유니언을 반환하는 함수
let returnStringOrUndefined: () => string | undefined;

// 타입은 string을 반환하는 함수나 undefined
let maybeReturnsString: (() => string) | undefined;
```

### 매개변수 타입 추론

- 인라인 함수를 포함하여 작성한 모든 함수에 대해 매개변수 타입을 선언해야한다면 번거로울 것이다.
- 타입스크립트는 **선언된 타입의 위치에 제공된 함수의 매개변수 타입을 유추할 수 있다.**

```tsx
let singer: (song: string) => string;

singer = function (song) {
	// song 매개변수는 string으로 유추된다.
	return `Singing: ${song.toUpperCase()}!`; // ok
}
```

```tsx
const songs = ["a", "b", "c"];

// song: string, index: number
songs.forEach((song, index) => { /** ... */ });
```

### 함수 타입 별칭

- 함수 타입도 타입 별칭을 사용할 수 있다.
- 반복적으로 작성하는 매개변수와 반환 타입을 줄여 코드 공간을 많이 절약할 수 있다.

```tsx
type StringToNumber = (input: string) => number;

let stringToNumber: StringToNumber;

stringToNumber = (input) => input.length; // ok

stringToNumber = (input) => input.toUpperCase(); // Error
```

```tsx
type NumberToString = (input: string) => string;

function usesNumberToString(numberToString: NumberToString) { /** ... */ }

usesNumberToString((input) => `${input}!`); // ok

usesNumberToString((input) => input * 2); // Error
```

## 그 외 반환 타입

### void 반환 타입

- 어떤 값도 반환하지 않는 함수의 반환 타입
    
    ```tsx
    function logSong(song: string | undefined): void {
    	if (!song) {
    		return; // ok
    	}
    
    	console.log(`${song}!`);
    
    	// 값 반환을 허용하지 않는다.
    	return true; // Error: Type 'boolean' is not assignable to type 'void'.
    } 
    ```
    
- 자바스크립트에서 return이 없으면 기본적으로 undefined를 반환한다. 하지만 반환 타입이 void로 추론되므로 undefined 타입에 할당할 수 없다.
    
    ```tsx
    function returnVoid() {
    	return;
    }
    
    let lazyValue: string | undefined;
    
    lazyValue = returnVoid();
    // Error: Type 'void' is not assignable to type 'string | undefined'.
    ```
    
- 반환 타입이 void인 함수로 선언되었다면 **함수에서 반환되는 모든 값은 무시**된다. **반환 값을 무시하도록 설정할 때 유용**하다.
    - 예를 들어 배열 내장 메서드 forEach는 void를 반환하는 콜백을 받는다. forEach에 제공되는 함수는 모든 값을 반환할 수 있다.
    
    ```tsx
    const records: string[] = [];
    
    function saveRecords(newRecords: string[]) {
    	newRecords.forEach(record => records.push(record));
    }
    ```
    
    ```tsx
    type Func = () => void;
    
    const func: Func = () => 1; // ok
    ```
    
- void 타입은 자바스크립트가 아닌 타입스크립트 키워드이다. 사용되거나 반환될 수 있는 값이 아니다.

### never 반환 타입

- 절대 값을 반환하지 않는 함수의 반환 타입
- never 반환 함수는 (의도적으로) 항상 오류를 발생시키거나 무한 루프를 실행하는 함수다.
- 다음은 fail 함수가 오류만 발생시키므로 param의 타입을 string으로 좁혀서 타입스크립트의 제어 흐름 분석을 도와주는 예시다.
    
    ```tsx
    function fail(message: string): never {
    	throw new Error(`Invariant failure: ${message}`);
    }
    
    function workWithUnsafeParam(prarm: unknown) {
    	if (typeof param !== "string") {
    		fail(`param should be a string, not ${typeof param}`);
    	}
    
    	param.toUpperCase();
    }
    ```
    

## 함수 오버로드

- 자바스크립트 함수는 선택적 매개변수와 나머지 매개변수만으로 표현할 수 없는 매우 다른 매개변수들로 호출될 수 있다. ⇒ **오버로드 시그니처 (overload signature)**
- 하나의 최종 **구현 시그니처(implementation signature)** 와 그 함수의 본문 앞에 서로 다른 버전의 함수 이름, 매개변수, 반환 타입을 여러번 선언한다.
- 오버로드된 함수 호출에 대해 구문 오류를 생성할지 여부를 결정할 때 함수의 오버로드 시그니처만 확인한다. 구현 시그니처는 함수의 내부 로직에서만 사용된다.

```tsx
function createDate(timestamp: number): Date;
function createDate(month: number, day: number, year: number): Date;
function createDate(monthOrTimestamp: number, day?: number, year?: number) {
	return day === undefined || year === undefined
		? new Date(monthOrTimestamp)
		: new Date(year, monthOrTimestamp, day);
}

createDate(55434142); // ok
createDate(7, 27, 1987); // ok

createDate(4, 1);
// Error: No overload expects 2 arguments,
// but overloads do exist that expect either 1 or 3 arguments.
```

- 자바스크립트로 컴파일되면

```tsx
function createDate(monthOrTimestamp, day, year) {
	return day === undefined || year === undefined
		? new Date(monthOrTimestamp)
		: new Date(year, monthOrTimestamp, day);
}
```

- 복잡하고 설명하기 어려운 함수 타입일 경우에만 최후의 수단으로 사용하자! 함수를 단순하게 유지하고 가능하면 함수 오버로드를 사용하지 않는 것이 좋다.

### 호출 시그니처 호환성

- 함수의 오버로드 시그니처에 있는 반환 타입과 각 매개변수는 구현 시그니처에 있는 동일한 인덱스의 매개변수에 할당할 수 있어야 한다. ⇒ 즉, 구현 시그니처는 모든 오버로드 시그니처와 호환되어야 한다.

```tsx
function format(data: string): string; // ok
function format(data: string, needle: string, haystack: string): string; // ok

function format(getData: () => string): string;
// Error: This overload signature is not compatible with its implementation signature

function format(data: string, needle?: string, haystack?: string) {
	return needle && haystack ? data.replace(needle, haystack) : data;
}
```
